# iChoice

OpenCart 3.0.3.8 application source for https://www.ichoice.com.hr.

Environment-specific configuration, customer data, image assets and runtime storage are not tracked.

The anchor-price module includes the audited admin register, bulk CSV import/export,
responsive storefront display, public CSV/XML daily price lists and 30-day archives.
See `docs/sidrene_cijene_pustanje_na_produkciju.md` for installation and EasyCron setup.
